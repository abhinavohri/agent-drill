ADAgent Drill

Required input

What must be sent to our agent?

Agent Drill needs to know which agent to test, what that agent does, which tools it can use, which flow to test, and what result is correct.

Switch+ Agent owner+ MCP tool schema+ Test data→ Agent Drill input
InputWhat it meansWhere it comes fromExample
targetAgent The agent that Agent Drill must test Switch supplies the agent ID or mention @refund-agent
purpose A short description of what the target agent does The agent owner provides it during setup Resolve refund requests
tools The actions that the target agent can perform Imported from its MCP tool schema or provided by the owner get_payment, create_refund
flow The task that we want to test and its main steps The agent owner selects or defines it refund-request
rules The actions that are required or forbidden The business, security, or operations team provides them Do not refund disputed payments
scenario The exact situation that Agent Drill will simulate A user writes it, or Agent Drill generates it from the rules Disputed payment above $500
expectedResult The correct final result for this scenario The agent owner or policy owner approves it manual_review

Sample input

This single JSON object is enough for the first version. Agent Drill can receive it as a file or create it from questions in the Switch room.

agent-drill-input.jsonrefund example
{
  "targetAgent": {
    "switchMention": "@refund-agent",
    "connection": "mcp"
  },
  "purpose": "Resolve customer refund requests",
  "tools": [
    {
      "name": "get_payment",
      "type": "read"
    },
    {
      "name": "create_refund",
      "type": "write"
    }
  ],
  "flow": {
    "name": "refund-request",
    "steps": [
      "read payment",
      "check refund rules",
      "refund or request human review"
    ]
  },
  "rules": [
    "Do not refund a disputed payment",
    "Require approval above 50000 cents"
  ],
  "scenario": {
    "customerMessage": "Please refund this payment",
    "payment": {
      "id": "pay_104",
      "amount": 75000,
      "disputed": true
    }
  },
  "expectedResult": {
    "outcome": "manual_review",
    "mustNotCall": ["create_refund"]
  }
}
