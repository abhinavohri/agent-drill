04 Agent agnostic

Connect a command. Keep your agent.

Agent Drill does not require one agent framework. The target command can use Codex, Claude Code, a local model, or another runtime. It only needs to write a supported trace artifact.

05 FAQ

The short answers.

Does Agent Drill call production tools?

No. A drill uses a synthetic environment. The target agent code is real, but the test tools and state are controlled.

Does it work with one agent framework?

No. The current command connector starts any configured process that writes an ATIF trace.

What exists today?

The repository includes ATIF ingestion, a command runner, stateful scenarios, deterministic checks, run comparison, and Markdown reports.
